# Data dictionary

## Scope

This dictionary describes the consolidated single-station ozone experiment. The principal observation source is OpenAQ sensor `1304560` at Bexley–Belvedere West, London, United Kingdom. Observation timestamps are handled in UTC. The hourly study period extends from 28 April 2021 through 31 December 2023.

The exact field names can vary between raw API responses and processed tables. The processed CSV files generated by the project scripts are the authoritative schema for each pipeline stage.

## Observation and model-dataset fields

| Field | Meaning |
|---|---|
| `fecha_utc` | Observation timestamp normalized to UTC in the hourly ozone dataset. |
| `valor_o3_modelo` | Ozone concentration used by the modelling workflow after the documented quality-control and preparation steps. |
| `particion` | Chronological data partition: `train`, `validation`, or `test`. |
| `hora_sin`, `hora_cos` | Cyclic encoding of hour of day. |
| `dia_anio_sin`, `dia_anio_cos` | Cyclic encoding of day of year. |
| `C_lag24` / lag-derived fields | Lagged ozone concentration features where present in the model dataset. Consult the generated CSV schema and training script for exact names. |

## Meteorological variables

Meteorological data were retrieved from the Open-Meteo Historical Weather API for the monitoring-site coordinates. The merged modelling dataset contains the following variables:

| Field | Meaning | Typical unit |
|---|---|---|
| `temperature_2m` | Air temperature at 2 m above ground | °C |
| `relative_humidity_2m` | Relative humidity at 2 m | % |
| `dew_point_2m` | Dew-point temperature at 2 m | °C |
| `wind_speed_10m` | Wind speed at 10 m | API-configured unit; verify request metadata |
| `wind_direction_sin` | Sine-transformed wind direction | dimensionless |
| `wind_direction_cos` | Cosine-transformed wind direction | dimensionless |
| `shortwave_radiation` | Surface shortwave radiation | API-configured unit; verify request metadata |
| `cloud_cover` | Total cloud cover | % |
| `precipitation` | Total precipitation over the API time interval | mm |

Wind direction is represented through sine and cosine components to avoid the discontinuity between 0° and 360°. Confirm the original request and API metadata when documenting units in a publication.

## Prediction-output fields

The detailed prediction table `o3_pinn_predicciones_detalladas.csv` contains model forecasts organized by target timestamp, forecast horizon, partition, and model. Its principal fields include:

| Field | Meaning |
|---|---|
| `fecha_objetivo` | Timestamp of the forecast target. |
| `horizonte_horas` | Forecast horizon in hours (1, 6, or 24). |
| `particion` | Chronological partition associated with the target. |
| `modelo` | Model identifier, such as `MLP_con_meteorologia`, `MLP_sin_meteorologia`, `Modelo_neuronal_fisico`, or `Persistencia`. |
| `o3_real` | Observed ozone concentration at the target time. |
| `o3_predicho` | Predicted ozone concentration. |
| `residuo` | Signed prediction residual as defined by the evaluation script. |
| `error_absoluto` | Absolute prediction error. |
| `error_cuadratico` | Squared prediction error. |

The exact number of available rows differs by horizon and partition because forecasts require valid input and target observations. Analyses comparing models on paired dates should use their common valid observations.

## Data provenance and quality control

- OpenAQ provides the ozone measurements and sensor metadata.
- Open-Meteo Historical Weather API provides the meteorological time series.
- The project stores timestamps in UTC for temporal alignment.
- Raw API responses are retained locally and are not committed to the repository.
- Quality-control flags, missing observations, gaps, duplicate timestamps, and valid numeric values are assessed by the audit and validation scripts.
- Missing ozone observations are not to be interpreted as zero concentration.
- The weather request metadata identifies ERA5, while the downloaded JSON filename contains `era5_land`. This naming/metadata discrepancy must be reconciled against the original request before specifying the exact reanalysis product in a publication.

## Interpretation cautions

The measured concentration is the result of multiple interacting processes, including emissions, transport, atmospheric chemistry, deposition, and boundary conditions. The model's learned source term and positive removal coefficient are effective parameters within a simplified equation. They are not direct measurements of emissions or separately identified physical rates.
